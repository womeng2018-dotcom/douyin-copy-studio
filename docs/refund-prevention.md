# 防退款治理 · 商品页面「三秒理解法」

> **文档定位**：P0 级治理文档（Growth OS 第八节落地细则）。目标是让用户在下单前 3 秒内理解全部关键信息，从源头消灭「信息不对称类退款」。
> **数据口径**：抖音来客后台归档——退款率峰值 **43.57%**；退款结构 **计划有变 40% + 买多买错 30%**（合计 **70%** 为下单前信息不对称导致）。
> **核心逻辑**：少一个退款 = 少浪费一次广告获客成本。

---

## 一、退款现状（事实）

| 指标 | 数值 | 判定 |
|------|------|------|
| 退款率峰值 | **43.57%** | P0，必须治理 |
| 计划有变 | **40%** | 用户行程不确定性，需「可退可约」预期管理 |
| 买多买错 | **30%** | 信息不清导致买错，需三秒理解法 |
| 其他 | **30%** | 服务/体验类退款，靠门店承接解决 |

---

## 二、商品页面「三秒理解法」六要素

用户看到团购页后 3 秒内必须获得 6 个答案：

| # | 要素 | 必答内容 | 放置位置 |
|---|------|----------|----------|
| ① | **做什么** | 项目名称 + 一句话描述（例：全身精油SPA 80分钟） | 标题 + 首图 |
| ② | **多久** | 服务时长，精确到分钟 | 标题 + 详情首屏 |
| ③ | **多少钱** | 实付价 + 划线价（价格锚点） | 标题 + 首图角标 |
| ④ | **适合谁** | 适用人群 + 不适用人群 | 详情 + 主图 |
| ⑤ | **怎么预约** | 预约方式（电话/线上）+ 是否需要提前 | 详情首屏 |
| ⑥ | **有没有限制** | 有效期、节假日限制、退改规则、男女通用性 | 详情 + 底部固定 |

## 三、防退款信息前置清单（制作团队逐项打勾）

### 3.1 团购标题（≤20字）

- [ ] 包含：品类 + 价格 + 时长（例："全身SPA 80分钟 99元"）
- [ ] 不出现模糊词（"超值""惊喜价"等无锚点词）
- [ ] 不含绝对化用语（"第一""最""顶级"）

### 3.2 主图（第一屏）

- [ ] 主图已含「品类 + 核心卖点 + 价格锚点」
- [ ] 价格数字放大，划线价清晰
- [ ] 限流信息角标（有效期 / 预约制）已上主图
- [ ] 适用人群标签可见（"男客可用""情侣""单人"）

### 3.3 详情页首屏

- [ ] 服务流程（做什么 → 多久 → 包含项）
- [ ] 预约方式首屏可见
- [ ] 退改规则明示（支持随时退 / 过期自动退 / 预约后不可退）

### 3.4 素材-商品一致性

- [ ] 视频素材承诺 = 团购页描述（时长 / 价格 / 项目一致）
- [ ] 视频未出现团购页没有的权益（防夸大）
- [ ] CTA 指向正确团购链接（团购视频→团购页，引流视频→门店定位）

## 四、文案层防退款规则（接入 Copy Studio 红线库）

| 规则 | 说明 |
|------|------|
| **预约前置告知** | 文案含预约提示："需提前2小时电话预约"类信息写进口播 |
| **有效期明示** | 口播/字幕明确有效期（"90天内有效"） |
| **退改预期管理** | 文案可写"随时可退"降低下单犹豫，同时明确预约规则 |
| **人群边界** | 明确"仅限男客/男女通用"，防止买错退款 |

---

## 五、治理目标与验证

| 阶段 | 退款率目标 | 验证方式 |
|------|-----------|----------|
| 30 天内 | 从 **43.57%** 降至 **25% 以下** | 每周后台拉退款数据 |
| 60 天内 | 降至 **20% 以下** | 按门店分层对账 |

**联动机制**：退款率纳入门店分层判定——连续 2 周退款率 > 30% 的 C 级店，禁止规模化投流（见 Growth OS 第七节）。

---

## 六、归因口径（防止误判）

- 退款率统计口径统一为：**退款笔数 ÷ 成交笔数**（按周、按门店、按素材三维归因）。
- 「计划有变」类退款 ≠ 素材问题，归因到商品页与预约体验；「买多买错」类退款归因到信息清晰度（三秒理解法覆盖率）。
- 广告素材引发的退款（承诺与实物不符）直接判定为素材问题，立即下架。

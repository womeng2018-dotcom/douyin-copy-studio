# 素材 5 模型实验模板（Material Models）

> **文档定位**：本地推「素材实验池」的每日生产模板。配合 Growth OS 第四节「本地推实验系统」使用。
> **用法**：每天从 5 个模型中产出 5～10 条素材 → 投入素材实验池 → 按数据漏斗（点击/完播/成交/退款/核销）判定 → Top 10% 进主计划。
> **数据口径**：抖音来客后台 2026-06-29 ~ 08-08 归档；CPA ¥0.19 王牌素材为**已验证事实**，其余模型为**待验证假设**。

## 二、各模型完整模板

### A 价格型（第一核心模型）

| 模块 | 内容要求 |
|------|----------|
| 钩子（0-3s） | 价格+品类+距离，首句即命中："XX附近99元做80分钟SPA" |
| 卖点（3-10s） | 环境、手法、时长换算单价（80分钟99元 ≈ 1.2元/分钟） |
| 信任（10-25s） | 门店实拍、连锁品牌、评价截图 |
| CTA（25-30s） | "左下角团购，先囤后约" |
| 合规注意 | 价格必须是真实团购价；不可写"仅此一天"等虚假紧迫 |

**已验证数据**：最优素材 CPA **¥0.19**、平均 CPA **¥0.81**（豫溪川 180条素材/¥2,280消耗/2,813笔转化）。

### B 价格+场景

| 模块 | 内容要求 |
|------|----------|
| 钩子 | 场景提问代入："XX附近下班以后不知道去哪？" |
| 卖点 | 场景 + 价格 + 时长："99块做80分钟SPA，解乏刚好" |
| 信任 | 下班后真实客流画面、技师状态 |
| CTA | 团购引导 + "适合下班顺路" |
| 合规注意 | 场景表述不得夸大功效（不得出现"治疗""缓解疾病"类词） |

### C 痛点+价格

| 模块 | 内容要求 |
|------|----------|
| 钩子 | 痛点直击："每天坐办公室肩颈特别累的……" |
| 卖点 | 痛点 → 解法 → 价格："这家99块可以做全身SPA" |
| 信任 | 顾客自述前后状态对比（合规范围内，不涉医疗） |
| CTA | 团购引导 + 人群标签"打工人必囤" |
| 合规注意 | 禁止"治疗颈椎病"类医疗宣称，只能描述体验感受 |

### D 体验+价格

| 模块 | 内容要求 |
|------|----------|
| 钩子 | 真人出镜+悬念："第一次来这家做SPA，没想到……" |
| 卖点 | 全流程记录：进门→环境→手法→结束感受 |
| 信任 | 真实体验过程（P1 必含：门店环境、服务过程、成品状态） |
| CTA | 团购引导 + 真实感受总结 |
| 合规注意 | 出镜人需有肖像授权；体验感受不得夸大 |

### E 对比型

| 模块 | 内容要求 |
|------|----------|
| 钩子 | 选择题开场："XX附近100块左右的SPA，到底怎么选？" |
| 卖点 | 横向对比：价格 / 环境 / 时长 / 评价，突出本店性价比 |
| 信任 | 对比表格字幕化呈现 |
| CTA | 团购引导 + "选我这家不踩坑" |
| 合规注意 | 对比不得贬低同行（合规红线：禁止贬低同行） |

## 三、爆款变量拆解体系（禁止直接复制爆款）

一个跑通的爆款 → 拆成 4 个变量交叉衍生：

| 变量 | 取值（示例） |
|------|-------------|
| **价格** | 99元 → 79元 → 109元 |
| **人群** | 上班族 / 出差人士 / 开车人士 / 宝妈 / 年轻女性 |
| **场景** | 下班 / 午休 / 出差 / 周末 / 晚上 |
| **表达方式** | 本人讲 / 顾客讲 / 技师讲 / 旁白 / 纯字幕 |

### 3.1 衍生矩阵（4变量 × 取值）

> **1个爆款 = 20～50条衍生素材**

示例：以「99元80分钟SPA」为母本——
- 价格维度：79元版、109元版（3条）
- 人群维度：上班族版、出差版、开车版（3条）
- 场景维度：下班版、午休版、周末版（3条）
- 表达维度：本人讲/顾客讲/技师讲/旁白/纯字幕（5条）
- 交叉组合：任选 2 个变量组合（如「出差人群 × 晚上场景」）≥ 10 条

### 3.2 拆解清单（爆款入库时提取）

| 维度 | 提取内容 |
|------|----------|
| 钩子 | 前3秒的完整话术与画面 |
| 结构 | 时间轴（0-3s / 3-10s / 10-25s / 25-30s 各放什么） |
| 节奏 | 镜头切换频率、字幕出现时机 |
| 画面 | 必含元素（门头/环境/服务过程/成品/真人） |
| 评论需求 | 评论区置顶话术、评论区高频问题 |

## 四、每日实验记录表模板

| 日期 | 门店 | 模型 | 变量组合 | 素材标题 | 消耗 | 点击 | 完播 | 成交 | 退款 | 核销 | CPA | 判定 |
|------|------|------|----------|----------|------|------|------|------|------|------|-----|------|
| 08-11 | 豫溪川 | A | 价格99 | 示例 | ¥50 | 1200 | 8.1% | 62 | 5 | 41 | ¥0.81 | 进主计划 |

**判定规则**：
- **进主计划**：CPA ≤ 平均 CPA 且 退款率 ≤ 门店均值，进入 Top 10%
- **继续观察**：点击高但完播低 → 钩子问题；完播高但成交低 → 卖点/CTA 问题
- **淘汰**：测试 3 天无成交信号

## 五、与 Copy Studio 的配合

- 本模板产出的是「素材方向与结构」，Copy Studio 负责把方向展开成**多条完整差异化口播脚本 + 分镜表 + 标题话题 + 评论区话术**，并自动完成红线自检。
- 建议工作流：本表选模型与变量 → Copy Studio 生成变体 → 人工拍摄 → 本地推测试 → 后台数据回填本表。

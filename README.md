# 抖音来客投流文案工作台 · Copy Studio

一个面向**本地生活投流（抖音来客 / 巨量本地推）**的文案生产工具，把《抖音来客投流素材需求说明书 V1.0》从静态文档变成可交互的生产力工具。

填参数 → 一键生成多条差异化口播脚本 + 分镜表 + 标题话题 + 评论区话术，并自动完成合规红线自检。

## 为什么做这个

投流素材的产能瓶颈通常不在拍摄，而在**前置的文案与 Brief 环节**：

- 制作团队拿到的需求口径不统一，反复返工
- 同一波次需要 9-15 条 A/B 变体，人工写钩子极耗时
- 美业/教培等垂类合规红线密集，事后被拒审再改成本极高

本工具把「需求说明书里的规则」直接固化成生成规则与校验规则，做到**产出即合规、产出即可交付**。

## 功能模块

### 1. 文案生成
- **7 个业务品类**：美发、生活美容、美甲美睫、餐饮、教培、健身、家装，各自独立的用词、场景、痛点与合规强度
- **3 档时长结构**：15s（强钩子拉新）/ 30s（团购转化主投）/ 45-60s（达人探店品牌），各自带时间码结构
- **5 类前 3 秒钩子**：利益点型、疑问型、冲突反常识型、身份代入型、痛点型（可指定，也可自动每条变体轮换）
- **4 种口播风格**：口语化、促销感、测评探店、剧情反转
- **一次输出 2-5 条差异化变体**，满足 A/B 测试要求
- 每条变体包含：带时间码的口播脚本、分镜表（画面/字幕/拍摄要点）、视频标题、话题标签、评论区置顶话术

### 2. 红线自检
- **三级风险分类**：P0 高压线（命中即返工）/ P1 高风险（建议改）/ P2 需自证
- 覆盖站外引流、医疗功效宣称、绝对化用语、虚假宣传、焦虑恐吓、贬低同行、价格合规、肖像版权等
- 文案中风险词**实时高亮**，逐条给出修改指引
- **一键净化**：P0 词自动替换或删除，并清理残留标点

### 3. Brief 速查
把说明书的目标优先级、受众画像、时长节奏、画面必含元素、红线清单、交付规格做成随查随用的卡片。

### 4. 交付验收 Checklist
11 项验收清单，勾选状态本地保存，制作团队自审与投流负责人复核共用。

### 5. 导出与历史
- 复制单条口播 / 复制整条 / 复制全部变体
- 一键导出 **Markdown 交付单**（含分镜表格与合规说明），可直接发给制作团队
- 最近 20 次生成记录保存在本机浏览器

## 本地使用

纯静态站点，无框架、无依赖、无需构建，双击 `index.html` 即可使用。

如需本地起服务：

```bash
cd copy-studio
python3 -m http.server 8899
# 浏览器打开 http://localhost:8899
```

运行引擎自测（校验生成质量与合规扫描）：

```bash
node test-engine.js
```

## 部署到 GitHub Pages

1. 推送代码到 GitHub 仓库的 `main` 分支
2. 进入仓库 **Settings → Pages**
3. **Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
4. 保存后约 1 分钟生成站点地址

后续修改推送到 `main` 会自动重新发布。

## 如何扩展

- **加新品类**：在 `js/data-category.js` 中新增一个 key，补齐 `scenes / pains / benefits / riskNote` 等字段；如需专属口播语感，在 `js/data-lines.js` 的 `DS.catLines` 中补 `process / feel` 句式
- **加新钩子句式**：在 `js/data-lines.js` 的 `DS.hooks` 对应类型下追加，支持 `{area} {entryPrice}` 等变量
- **更新红线词**：在 `js/data-compliance.js` 的 `DS.riskRules` 中按 P0/P1/P2 追加；若可自动替换，同时在 `DS.replaceMap` 补映射
- **调整时长结构**：在 `js/engine.js` 的 `DS.durations` 中修改分段时间轴与画面提示

## 重要提示

工具输出为**创作参考**。正式投放前必须人工确认：

- 价格、套餐内容、限时期限与抖音来客后台**完全一致**
- 出镜人员肖像授权覆盖投流用途，BGM 与字体具备商用授权
- 涉及仪器、医美、学科培训等项目须核对经营范围与资质

红线扫描基于关键词匹配，可作为第一道过滤网，**不能替代平台审核与法务复核**。
